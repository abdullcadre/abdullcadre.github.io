## <img src="https://api.iconify.design/ic/round-palette.svg?color=%2336BCF7" width="24" height="24" align="center" alt="" /> My UI/UX Principles

> **Good design is not decoration. It's how the product works.**

| Principle | What it means in my work |
|:---|:---|
| <img src="https://api.iconify.design/ic/round-explore.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> **Clarity first** | Each screen has one main goal and one obvious primary action |
| <img src="https://api.iconify.design/ic/round-sync.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> **Consistency** | Same colors, spacing, icons and behavior across the whole app |
| <img src="https://api.iconify.design/ic/round-layers.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> **Visual hierarchy** | Size, weight and contrast guide the eye |
| <img src="https://api.iconify.design/ic/round-bolt.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> **Immediate feedback** | Every action gets a response: loading, success or error |
| <img src="https://api.iconify.design/ic/round-health-and-safety.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> **Error prevention** | Validate early, confirm destructive actions, explain how to recover |
| <img src="https://api.iconify.design/ic/round-accessibility-new.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> **Accessibility** | Readable text, strong contrast, never color alone |

### <img src="https://api.iconify.design/ic/round-devices.svg?color=%2336BCF7" width="24" height="24" align="center" alt="" /> Rules per platform

| <img src="https://api.iconify.design/ic/round-smartphone.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> Mobile | <img src="https://api.iconify.design/ic/round-desktop-windows.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> Desktop | <img src="https://api.iconify.design/ic/round-language.svg?color=%2336BCF7" width="18" height="18" align="center" alt="" /> Web |
|:---|:---|:---|
| Touch targets of at least 48dp | Full keyboard navigation and shortcuts | Mobile-first, responsive layouts |
| Key actions within thumb reach | Layouts that adapt to window resizing | Fast loading, light pages |
| Follow platform conventions | Hover, focus and tooltip states | Semantic, accessible markup |
| Handle offline and slow networks | Use space for productivity, not clutter | Clear navigation on every page |
